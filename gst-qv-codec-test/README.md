
# gst-qv-codec-test

This directory contains GStreamer test applications designed to validate various functionalities of video codecs.

## Applications

### 1. `test_seek`

A simple GStreamer test application used to test the seek feature for video playback.

#### Usage

```bash
test_seek [FILENAME]
```

- **FILENAME**: The path to the video file you wish to test.

#### Example

```bash
test_seek /path/to/video.mp4
```

This command will perform 5 random seek operations and 5 pause tests on the specified video file.
